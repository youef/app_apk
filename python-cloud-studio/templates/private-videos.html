01

اكتشاف مصادر الفيديو والحلقات

ابدأ بصفحة موقع عامة، وليس بالضرورة رابط MP4 مباشرًا

الفحص المتعدد يجرب BeautifulSoup ثم إعدادات JavaScript ثم yt-dlp ثم Chromium ويفحص روابط الحلقات واحدًا تلو الآخر، دون تجاوز DRM أو رفض الخادم.

لم يبدأ فحص الصفحة.
الفحص الشامل: HTML ← إعدادات JS ← yt-dlp ← Chromium ← جميع صفحات الحلقات المكتشفة.
ستظهر مصادر MP4 وM3U8 المرشحة بعد الفحص.
لم تُكتشف صفحات حلقات.
لم تُكتشف مشغلات مضمّنة.
اضغط «فحص Chromium المتقدم» لتحليل الشبكة.
02

اختبار رابط الفيديو المباشر

تحقق من استجابة المصدر، بنية البث، المسارات والمدة

اختر رابطًا من نتائج الاكتشاف أو ألصق مصدرًا مباشرًا للاختبار.
03

حفظ الفيلم في التخزين الخاص

تحقق من البيانات والترخيص قبل التنزيل والرفع

يُحفظ الفيلم كمسودة في aseel_movies، ويُنشأ له مسار مشاهدة خاص بالحساب. تنزيل الملفات الكبيرة يعتمد على سعة خادم Render وإعدادات Supabase.
