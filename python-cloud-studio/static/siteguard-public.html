الخادم والبنية

نسخة PHP وقاعدة البيانات لا يمكن تأكيدهما خارجيًا إذا لم يعلنهما الخادم. كشف إصدار لا يثبت وجود ثغرة. التقرير لا يضمن خلو الموقع من SQLi أو XSS أو RCE.

DNS / NSLOOKUP

السجلات المعروضة عامة وقد تشير إلى CDN أو Reverse Proxy وليس إلى خادم الموقع الأصلي.

SSL / TLS

للعثور على عنوان الخادم الأصلي الخاص بك استخدم لوحة الاستضافة أو إعدادات DNS الخاصة به؛ لا يمكن إثباته من DNS العام عند وجود CDN.
