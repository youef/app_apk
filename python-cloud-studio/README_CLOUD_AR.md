# استضافة موقع العز TV Python Studio v5

**تحديث AutoSync:** إعداد العامل المستقل، والمصادر الدائمة، ولوحة «المزامنة الذكية» موثق في [README_AUTOSYNC_AR.md](README_AUTOSYNC_AR.md). رابط الخدمة الحالية: [استوديو العز TV](https://app-apk-oquy.onrender.com/). اتبع تعليمات AutoSync لتفعيل اتصال العامل والتحقق من حالته؛ استجابة موقع الويب وحدها لا تثبت عمل المزامنة.

هذا المشروع **خادم Python FastAPI كامل**، لا يحتاج CMD على جهازك بعد نشره إلى الاستضافة. يعطيك رابط HTTPS عامًا للدخول لكن **لوحة الإدارة محمية بكلمة مرور خاصة بالموقع** ثم بحساب Supabase المسؤول للحفظ في قاعدة البيانات.

## الأنسب: Render مع قرص دائم

1. ارفع محتويات مجلد المشروع (وليس ملف ZIP وحده) إلى مستودع GitHub خاص.
2. في https://dashboard.render.com اختر New > Blueprint وحدد المستودع الذي يحتوي `render.yaml` في الجذر.
3. سيطلب منك `ALEZZ_SITE_PASSWORD`؛ اختر كلمة مرور قوية **من 12 حرفًا على الأقل**. تتم توليد `ALEZZ_SITE_SECRET` تلقائيًا، و`ALEZZ_PUBLIC_MODE=1` تلقائيًا.
4. المفتاح `ALEZZ_TMDB_API_KEY` اختياري: أضفه يدويًا من صفحة متغيرات البيئة إذا أردت بيانات أغنى من TMDB.
5. وافق على خطة **Starter المدفوعة والقرص الدائم 1GB** إذا كانت التكلفة مناسبة. لا تختَر خطة مجانية إذا كنت تحتاج استمرار الفهرسة وحفظ حالة SQLite.
6. بعد اكتمال النشر تحصل على عنوان من `https://...onrender.com`. ادخل بكلمة مرور الموقع ثم من داخل الواجهة سجّل الدخول بحساب Supabase المسؤول لحفظ الأعمال.

## بديل: Railway

1. افتح https://railway.com، أنشئ مشروعًا من مستودع GitHub الذي يحتوي `Dockerfile` و`railway.json`.
2. في Settings > Networking اضغط Generate Domain لتفعيل رابط HTTPS.
3. في Variables أنشئ `ALEZZ_PUBLIC_MODE=1` و`ALEZZ_SITE_PASSWORD` (12 حرفًا وأكثر) و`ALEZZ_SITE_SECRET` (32 حرفًا وأكثر، قيمة سرية عشوائية) و`ALEZZ_DATA_DIR=/data`.
4. أضف Volume دائم إلى نفس الخدمة بمسار **`/data`**. بدون القرص ستفقد سجل الفهرسة بعد إعادة التشغيل أو النشر.
5. اجعل عدد النسخ 1 لأن قائمة SQLite محلية وحالة الجلسات في الذاكرة.

## ماذا يعمل على السحابة؟

- واجهة الويب العربية بكل أقسامها.
- فهرسة روابط المكتبات والقوائم العامة ومتابعة الصفحات والحلقات لاحقًا في عامل بالخلفية ضمن خدمة تعمل باستمرار.
- حفظ موضع الاستكمال في `ALEZZ_DATA_DIR/library_sync.sqlite3` على القرص الدائم.
- جلب الأسماء الأصلية والسنة والتصنيفات والصور من الصفحات العامة مع مصادر بيانات وصفية إضافية عند توفرها.
- مراجعة المسودات وحفظ البيانات إلى نفس Supabase عبر تسجيل دخول المسؤول.
- فحص روابط HTTPS العامة وMP4/HLS حيث يسمح المصدر بذلك.

**غير متاح من خادم السحابة:** التحكم في إضافة FetchV في متصفحك، أو تشغيل Microsoft Edge على كمبيوترك البعيد. انسخ الروابط من الإضافة إلى الواجهة يدويًا. كذلك قد تمنع بعض المواقع خوادم الاستضافة من الوصول إليها؛ لا يمكن ضمان استخراج حلقاتها كاملة أو استمرار توفر كل رابط.

### أمان وملاحظات

- لا تضع أسرار Supabase أو كلمة مرور موقعك في GitHub أو ملفات HTML؛ استخدم متغيرات البيئة على الاستضافة.
- لا تنشر المشروع بدون `ALEZZ_SITE_PASSWORD` و`ALEZZ_SITE_SECRET`؛ الموقع يرفض بدء التشغيل في `ALEZZ_PUBLIC_MODE=1` إذا لم يكونا صالحين.
- يلزم HTTPS لاستقبال ملف تعريف ارتباط الدخول في الوضع العام.
- فهرسة المحتوى لا تعني منح حقوق عرض الفيديو أو الصور. الحفظ كمسودات متاح، والنشر العام يخضع لقواعد المشروع.
- عند إعداد خدمة جديدة يلزم ربط حسابك بالاستضافة ورفع المستودع ثم تفعيل الخطة الدائمة إن أردتها. الخدمة الحالية تُحدّث من المستودع المرتبط؛ تحقق من حالتها بعد كل نشر.
- مفتاح TMDB اختياري وله شروط استخدام خاصة بالمصدر.

## اختبار محلي في وضع نشر آمن (بدون Docker)

```bash
export ALEZZ_PUBLIC_MODE=1
export ALEZZ_SITE_PASSWORD='CHANGE_TO_A_STRONG_SECRET_2026'
export ALEZZ_SITE_SECRET='CHANGE_TO_AN_INDEPENDENT_40_CHARACTER_SECRET'
export ALEZZ_DATA_DIR='./persist'
uvicorn server:app --host 127.0.0.1 --port 8765
```

يمكن تشغيل وضع الكمبيوتر القديم بالأمر `python launch.py` دون تغيير إعداداته، بشرط عدم وضع `ALEZZ_PUBLIC_MODE=1`، مع الإبقاء على استضافة الخادم المحلي في `127.0.0.1`.
