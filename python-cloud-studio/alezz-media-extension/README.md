# العز لالتقاط الوسائط 2

في Edge افتح `edge://extensions` وفي Chrome افتح `chrome://extensions`. للإضافة المثبتة سابقًا اضغط **إعادة تحميل**. للتثبيت الأول فعّل وضع المطوّر واختر **تحميل إضافة غير مضغوطة** وحدد هذا المجلد.

1. افتح الإضافة واضغط **تفعيل الالتقاط التلقائي** مرة واحدة. يحتاج الالتقاط إذن قراءة طلبات مواقع HTTP وHTTPS لتغطية خوادم البث الخارجية.
2. افتح صفحة الفيديو. تلتقط الإضافة عناوين الفيديو من الصفحة ومن الطلبات التي يرسلها المشغّل، وتعرض العدد على أيقونتها. إذا كانت الصفحة تؤجل طلب الفيديو، شغّله ليبدأ الطلب.
3. انسخ الرابط وحده أو أدخل الموسم والحلقة لنسخه بصيغة `S01E02|https://...`. الصقه في نافذة روابط الوسائط داخل الاستوديو.

النتائج منفصلة لكل تبويب، وتمحى عند التنقل إلى صفحة أخرى في التبويب، أو إغلاقه، أو إعادة تشغيل المتصفح. يبقى تفضيل الالتقاط محفوظًا. النسخ يحافظ على التوقيع الكامل للرابط. يمكن ربط صفحة HTTPS بالاستوديو المحلي على المنفذ 8765. بعد الربط، تُرسل الروابط الجديدة من الصفحة نفسها للتحقق والحفظ إذا كان الاستوديو مفتوحًا والمسؤول مسجل الدخول. عند ربط حلقة، أدخل رابط المسلسل ورقمي الموسم والحلقة.

الفيديو المباشر يدعم **تنزيل الملف**. تعرض الإضافة روابط قوائم HLS وDASH، ويقرأ **فحص نوع البث** القائمة عند الطلب لتحديد البث المباشر أو المسجّل. قائمة الجودات الرئيسية وحدها قد لا تحدد النوع، وبعض الخوادم تتطلب جلسة المتصفح لقراءة القائمة. تسجيل البث ودمج المقاطع ليس جزءًا من هذا الإصدار.
