# الفحص السريع والتجديد التلقائي

عند اكتشاف عمل، تُحفظ صفحة المصدر الأصلية وصفحتها النهائية بعد التحويل مع الصور والبيانات وروابط المشغلات في القرص الدائم. إعادة فتح نفس الرابط خلال خمس دقائق تعرض البيانات المحفوظة، ويُعاد التحقق من الفيديو عند طلب فحصه. يمكن للعملاء إرسال `force_refresh: true` إلى `/api/discover` لتجاوز النسخة المؤقتة.

الفحص يعالج ثلاث حلقات بالتوازي افتراضيًا، ويُظهر نتيجة كل حلقة فور اكتمالها. يمكن مراجعة بيانات العمل أثناء الفحص؛ تبقى أزرار تعديل روابط التشغيل والنشر معلقة حتى ينتهي. لا يعيد التحديث الدوري كتابة تعديلات حقول البيانات غير المحفوظة في الشاشة. مهلة عملية استخراج وفحص الروابط نحو 45 ثانية لكل حلقة، وقد تزيد قليلًا مع بدء المتصفح أو استجابة الشبكة؛ ليست وعدًا بفحص لحظي لموقع خارجي.

تُقرأ صور الغلاف المؤجلة من `data-src` و`data-original` بدل صورة الانتظار الصغيرة، وتُعرض الصورة كاملة دون قص. تُحفظ روابط الصفحات ونتائج آخر فحص حتى بعد إغلاق المتصفح أو إعادة تشغيل الخادم.

بعد حفظ العمل في المكتبة مرة واحدة، يتولى العامل الموجود فحص روابطه كل خمس دقائق وإعادة استخراجها كل 30 دقيقة افتراضيًا، وتقديم موعد التجديد عند معرفة انتهاء صلاحية التوقيع. لا يلزم إبقاء صفحة الاستوديو مفتوحة. يجب أن يكون العامل مفعّلًا والخادم يعمل مع القرص الدائم ومفتاح قاعدة البيانات السري؛ الخادم المتوقف لا يجدد الروابط. تُستخدم قراءة الصفحة بالمتصفح تلقائيًا إذا قطع المصدر اتصاله المباشر. لا يُستبدل رابط التشغيل ببديل إلا بعد اجتيازه فحص الفيديو.

يتحقق العامل من البيانات الناقصة في الأفلام والمسلسلات المحفوظة كل ست ساعات أثناء دورات الاستخراج، ويملأ الحقول الناقصة فقط. لا تُختلق سنة أو صورة خلفية إذا لم تتوفر في المصدر. إذا لم توجد خلفية مستقلة، يمكن استخدام الغلاف للعرض، ثم استبدال هذه النسخة بخلفية فعلية عند توفرها.

## الإعدادات الاختيارية

- يفحص الاستوديو حتى ثلاث حلقات معًا. تشغيل Chromium محدود بنسختين متزامنتين لتقليل استهلاك الذاكرة.
- `ALEZZ_TMDB_API_KEY`: استكمال البيانات والصور عبر TMDB إذا كان المفتاح مهيّأً.
- `ALEZZ_GOOGLE_API_KEY` و`ALEZZ_GOOGLE_SEARCH_ENGINE_ID`: بحث Google الاحتياطي للحسابات القائمة فقط. لا يُجرى أي طلب دون الإعدادين، وتُرفض النتائج ذات الاسم أو السنة غير المطابقين.

حسب [توثيق Google](https://developers.google.com/custom-search/v1/overview)، أُغلق Custom Search JSON API أمام العملاء الجدد وسيتوقف في 1 يناير 2027. هذا التكامل اختياري للحسابات القائمة، ولا يعتمد عليه جلب بيانات المصدر أو تجديد التشغيل.

اختبار المثال `فيلم طحين ودبس` عثر على ثلاثة روابط مباشرة اجتازت التحقق، واستخرج صورة الغلاف الكاملة والوصف من الصفحة. صلاحية الروابط ومدة الاستخراج تتغيران بحسب استجابة المصدر.
