# العز TV — AL EZZ TV

**الإصدار التجريبي v4.0 (إصلاح التثبيت على Android 4.4.4)**

العز TV واجهة تلفزيونية عربية بتصميم سينمائي أصلي، مع صفوف عرض أفقية وبحث وقنوات مباشرة ومحتوى الأطفال. تشغل مصادر MP4 أو HLS داخل التطبيق فقط وتستخدم كتالوج Supabase الحالي دون تغيير قاعدة البيانات أو حسابات المستخدمين.

- **Android TV:** دعم API 19 / Android 4.4.4 وشاشات Huidi، تحكم بالريموت، وضع خفيف، متابعة المشاهدة وتبديل الجودة.
- **الويب:** قائمة جانبية ونظام عرض سينمائي، بحث مباشر، مفضلة، متابعة المشاهدة ومحتوى متجدد.
- **الأطفال:** قسم مستقل للمحتوى المراجع مع التصفية حسب الدولة واللغة والنوع.
- **iOS:** تطبيق تجريبي لمحاكي iPhone؛ وليس IPA قابلاً للتثبيت على iPhone الفعلي.
- **الإدارة:** لوحة إدارة للحقوق والمحتوى عبر GitHub Pages.

## التوافق واستمرارية المستخدم

المعرّف التقني لتطبيق Android مستمر باسم sa.aseel.tv.cinema كما أن جداول aseel_* والذاكرة المحلية للمفضلة لم تتغير حفاظًا على التوافق. توقيع Debug المبني في GitHub Actions قد يختلف بين الإصدارات، لذا نجاح CI لا يضمن القدرة على تثبيت التحديث فوق نسخة بتوقيع مختلف. لا تحذف النسخة السابقة قبل نسخ بياناتك. تشغيل HLS الفعلي على Android 4.4.4 يحتاج اختبارًا على الشاشة لأن قدرة الجهاز على فك الترميز ليست مضمونة.

المشروع يتضمن: app/ و web/ و admin/ و ios/ و scripts/ و docs/. مصادر البث تتطلب توفر الحقوق والملف المباشر؛ قوائم IPTV لا تعني ترخيص إعادة البث.

## إصلاح مشكلة «التطبيق ليس مثبتًا»

- الإصدار الجديد يحمل معرّفًا منفصلًا **sa.alezz.tv.kitkat**؛ لا يحاول تحديث التطبيق القديم **sa.aseel.tv.cinema** بتوقيع مختلف.
- يجري الاختبار على APK كامل واحد، وليس حزمة APKs أو ملف ZIP، ويتأكد من minSdk19 وDEX035 وARMv7 والتوقيع V1.
- هذه نسخة تثبيت **مستقلة**، ولذلك لن تنقل التفضيلات المحلية القديمة تلقائيًا. لا تحذف التطبيق السابق لحين اختبار الجديد.
- التحديثات اللاحقة تتطلب مفتاح توقيع ثابتًا محفوظًا في GitHub Secrets. راجع docs/INSTALL_TROUBLESHOOTING_KITKAT.md.

## YouTube TV v7
- إضافة خانة YouTube مستقلة في لوحة الإدارة، مع دعم الروابط الرسمية `youtube.com/watch` و`youtu.be` و`shorts` و`live`.
- رابط YouTube يعمل داخل نافذة المشاهدة باستخدام YouTube IFrame API الرسمي، وليس عبر استخراج MP4.
- في Android يوجد قسم «يوتيوب» للصق الرابط وتشغيله بمشغّل داخل التطبيق والتحكم بالريموت.
- في الويب يوجد مسار [يوتيوب](https://youef.github.io/app_apk/?section=youtube) مع لصق الروابط والتصفح بالأسهم.
- رابط إصدار [العز TV v7 APK](https://github.com/youef/app_apk/releases/tag/al-ezz-tv-youtube-api19-v7).
- Android 4.4.4 قد لا يدعم مشغل YouTube HTML5 في WebView الافتراضي؛ دعم بنية APK لا يضمن تشغيل YouTube على الجهاز.

### تفعيل الدخول مرة واحدة
يدخل صاحب الشاشة الرمز المكون من ستة أرقام لمرة واحدة ثم يُحفظ نجاح التفعيل في SharedPreferences الخاص بحزمة sa.alezz.tv.unified. لا يُطلب الرمز عند إعادة تشغيل التطبيق أو الجهاز ما لم تُمسح بيانات التطبيق أو يُستبدل بمعرّف حزمة مختلف. صفحة الويب تفعل ذلك باستخدام localStorage المحلي بالمتصفح؛ لا تنتقل حالة التفعيل تلقائيًا بين الأجهزة ولا تمنع تجاوز التطبيق والوصول إلى REST العامة. مسؤول لوحة الإدارة يجب أن يستخدم Supabase Auth + RLS؛ رمز المشاهدة ليس حساب إدارة.

### واجهة التلفزيون والويب
- قائمة جانبية، ريموت بالأربعة اتجاهات وزر OK، أفلام ومسلسلات وقنوات وقسم أطفال ويوتيوب رسمي.
- الويب فيه وضع تلفزيون وملء شاشة اختياري، عرض سينمائي، بحث، مفضلة واستكمال المشاهدة.
- صفوف رئيسية مدارة في Supabase، مع أقسام أولية «مختارات العز»، «عالم العائلة والأطفال» و«على الهواء الآن».
- مصادر البث غير المرخصة أو غير المعتمدة لا يجب نشرها؛ الفحص التقني ليس إذن إعادة البث.

### لوحة الإدارة والعلاقات
- واجهة Al Ezz Studio فيها قوائم للمكتبة والمواسم والحلقات وحقوق المصادر وتنظيم الرئيسية والإعدادات، ومؤشرات المحتوى ومراجعات الحقوق.
- جداول aseel_home_collections وaseel_home_collection_items تربط الصفوف مباشرة بالأفلام والمسلسلات والقنوات والحلقات، مع منع الجمع بين أكثر من نوع عنصر في صف.
- حقل source_id يربط المحتوى بسجل من aseel_content_sources بمفتاح أجنبي، وفلاتر للعمر والترتيب مع استمرار التصنيفات والمواسم.
- RLS الجديدة لا تُظهر للعموم الصفوف غير الفعالة أو العناصر التي لم تعتمد حقوقها.
- رُبط عملان بجهة Blender على أساس روابط ترخيص متطابقة؛ بقية المصادر تحتاج مراجعة تحريرية ولا تُربط بالتخمين.

### حدود مؤكدة
APK الجديد حزمة مستقلة عن v7 لأن شهادات Debug كانت تتغير بين تشغيلات GitHub Actions. لاستمرار التحديثات بنفس الحزمة دون حذف بياناتها يجب إعداد شهادة توقيع ثابتة في GitHub Secrets. نجاح GitHub Actions فحص ثابت، وليس اختبار تثبيت وتشغيل ريموت أو مشغل على شاشة Huidi الفعلية. صفحات GitHub Pages والـPIN المحلي ليست بديلًا عن حماية API المتقدمة.
