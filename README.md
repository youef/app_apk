# YouTube TV Legacy (Android 4.4.4)

تطبيق Android TV أصلي خفيف، واجهته عربية، يدعم التنقل بالريموت ويستهدف Android 4.4.4 (API 19).

## ما الذي يقدمه؟
- شاشة رئيسية مناسبة للتلفزيون وأزرار تركيز واضحة للريموت
- البحث في يوتيوب عبر WebView
- تشغيل روابط الفيديو عبر مشغل YouTube الرسمي المضمن (IFrame)
- فتح الفيديو أو الموقع في المتصفح أو تطبيق يوتيوب المثبت
- المفضلة وآخر فيديو محفوظان محليًا، بدون حساب أو جمع بيانات
- زر رجوع وخيار شاشة كاملة وعرض أخطاء الاتصال
- ملف APK واحد للتثبيت على Android 4.4.4 وأعلى

## حدود التوافق المهمة

**لا يمكن ضمان تشغيل فيديوهات YouTube على Android 4.4.4.** نظام WebView القديم
قد لا يحقق متطلبات Google الحديثة (HTTPS/TLS، JavaScript، أو سياسات المشغل).
التطبيق يستخدم مشغل YouTube المضمن الرسمي ولا يفك تشفير روابط YouTube، ولا
يتجاوز سياسات المنصة. تثبيت APK على API 19 لا يعني دعم يوتيوب من خوادم Google.

## البناء
يتطلب JDK 11 وAndroid SDK 33 وGradle 7.6 وAndroid Gradle Plugin 7.4.2.

```bash
gradle --no-daemon :app:assembleDebug
```

ملف الإخراج: `app/build/outputs/apk/debug/app-debug.apk`

يمكن استخدام GitHub Actions الموجود في `.github/workflows/build-android.yml`
لبناء ملف APK وتحمليه من Artifacts.

## التثبيت
1. انسخ `app-debug.apk` إلى ذاكرة USB أو نزّله من متصفح التلفزيون.
2. الإعدادات > الأمان > السماح بمصادر غير معروفة (عند الحاجة).
3. افتح APK وثبّته. إن ظهرت مشكلة توقيع مع إصدار سابق من نفس الحزمة، احذف الإصدار السابق أولًا.
4. شغّل البرنامج من قائمة التطبيقات.
5. جرّب البحث والفيديو والمشغل الخارجي.

## التوافق
`minSdkVersion 19` = Android 4.4، شاملًا 4.4.4.
لم يُختبر على طراز التلفزيون الفعلي. يستخدم واجهات أندرويد فقط دون مكتبات خارجية.
التطبيق مستقل وغير تابع لـ Google أو YouTube.
