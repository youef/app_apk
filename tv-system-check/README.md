# Aseel TV System Inspector

تطبيق تشخيص آمن لـ Android 4.4.4 (API 19)، يعمل بالريموت ومن دون إنترنت، يقرأ بيانات الشاشة، يفحص اختيارياً توفر صلاحيات root الموجودة، ويفتح شاشة تحديث الشركة إن وجدت. التطبيق لا يخترق الجهاز، ولا يثبت Root، ولا يفلش ROM.

المعمارية ARMv7 مدعومة، والتطبيق مستقل عن ASEEL TV. لا تستخدم روم يحمل PC822 فقط دون إثبات تطابق الشركة واللوحة والمعالج والـ LCD panel.

## APK
عند اكتمال workflow، نزّل الـ APK من تبويب Actions -> Artifacts باسم Aseel-TV-System-Inspector-Android-4.4.4 ثم ثبته على الشاشة. معرف الحزمة مختلف عن تطبيق أسيل الأساسي.

## Why no automatic OS upgrade?
تغيير إصدار Android يتطلب صورة نظام مناسبة للوحة وإمكانات recovery/bootloader. نجاح الروت وحده لا يصنع رومًا متوافقًا، وقد تفسد الصورة غير المطابقة الجهاز.
