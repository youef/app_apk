# Huidi Home — ثيم وواجهة رئيسية لشاشة Huidi SMART_PC822

تطبيق Launcher منفصل عن «العز TV»، لتخصيص الصفحة الرئيسية للتلفزيون (لا يعدّل النظام ولا يحذف المشغّل الأصلي).

## المميزات

- Android 4.4.4 / API 19 فما فوق؛ كود Java أصلي دون WebView أو إنترنت أو مكتبات كبيرة.
- ثيمات: ذهبي فاخر، أحمر سينمائي، أزرق ليلي، وخلفيات متدرجة خفيفة دون صور كبيرة.
- صفحة رئيسية بالعربية RTL، ساعة محلية، اختصارات ومربع بارز لـ«العز TV» **إذا كان مثبتًا**.
- قائمة التطبيقات المثبتة فعليًا، أيقونات حقيقية، تحكم بالريموت وD-pad + OK.
- زر MENU أو الضغط المطوّل على OK لإضافة/إزالة التطبيق من المفضلة.
- وضع خفيف للشاشات القديمة (18 بطاقة بدلاً من 36 في صفحة التطبيقات)، ومزامنة قائمة التطبيقات عند العودة.
- إعدادات النظام والطريقة اليدوية لاختيار التطبيق كمشغّل HOME افتراضي.
- لا صلاحية إنترنت، لا حسابات، لا تعقّب، لا إعلانات.

## التثبيت

1. نزّل `huidi-home-android44.apk` من GitHub Releases.
2. انسخه على USB وافتح مدير الملفات في شاشة Huidi وثبّته من مصدر موثوق.
3. افتح **Huidi Home | بيتي**. بعد تجربته اضغط زر Home في الريموت؛ إذا ظهر الاختيار حدده ثم اختر «دائمًا».
4. إن لم يظهر الاختيار: إعدادات Android ← التطبيقات ← المشغّل الحالي ← مسح الإعدادات الافتراضية، ثم اضغط Home.
5. **للعودة للثيم القديم:** افتح إعدادات النظام من داخل Huidi Home، ثم غيّر التطبيق الافتراضي أو امسح الافتراضيات، أو أزل Huidi Home.

> الجهاز قد يُقفل المشغّل الأصلي على مستوى الشركة المصنعة. نجاح تثبيت APK لا يضمن أن زر HOME سيسمح بتغييره. التطبيق لا يبدّل لوحة إعدادات المصنع ولا واجهة HDMI ولا البرامج الأخرى.
> أول اختبار على الجهاز الحقيقي مطلوب لتأكيد توافق الريموت والخطوط والأيقونات.

## مشروع مستقل داخل المستودع

`cd huidi-launcher && gradle assembleDebug`. للبناء الرسمي يستخدم GitHub Actions مفتاح التوقيع المحمي الموجود بالفعل في Secrets، وتُنشر حزمة منفصلة `sa.youef.huidi.launcher` بتوقيع V1 المتوافق مع Android 4.4.4.


## تحديث Glass Edition — زجاجي بالكامل

- خلفية ليلية بتوهج لوني وخطوط دقيقة، باستخدام Android Canvas فقط لتقليل استهلاك الذاكرة.
- بطاقات متدرجة شفافة بحواف مضيئة وزوايا ناعمة، وتأثير تركيز متجاوب مع الريموت.
- ستة ثيمات: ذهبي فاخر، أحمر سينمائي، أزرق جليدي، بنفسجي ملكي، زمردي، وردي مخملي.
- قائمة علوية وبطاقات ونافذة إعدادات معاد تصميمها، وصفحة مستقلة لمعرض الثيمات.
- **مركز المطوّر:** يعرض حالة العلم المعلن من النظام، ويفتح خيارات المطوّر إن توفرت، أو يوجّه لصفحة «حول الجهاز» لتفعيلها بالضغط على رقم البناء ٧ مرات. التفعيل الحقيقي يتم بموافقة المستخدم من إعدادات Android ولا يُتجاوز بأوامر سرية أو صلاحيات خاصة.
- على Android 4.4 لا يوجد تمويه خلفية حقيقي (blur) آمن وسريع مثل الأنظمة الحديثة؛ هنا التأثير زجاجي متدرج لا يستهلك صورًا أو GPU ثقيلًا.

## Huidi Home Pro — Final APK

- العز TV يظهر في البطاقة الرئيسية عندما يكون مثبتًا، مع اختصار التشغيل.
- لوحة بيانات محلية: الذاكرة الحرة، التخزين المتاح، حالة الواي فاي، البطارية إذا كانت تعرضها الشاشة، إصدار Android وخيارات المطوّر.
- مركز الصيانة: مسح مؤقتات Huidi Home فقط، تحديث قائمة التطبيقات، ووضع خفيف قابل للتبديل. لا يدّعي تنظيف RAM كاملة أو إصلاح التطبيقات الأخرى.
- أربع خلفيات مرسومة بـ Android Canvas، بدون صور ثقيلة: Aurora / Nebula / Grid / Minimal.
- قفل اختصارات التطبيق داخل اللانشر برمز 6 أرقام، محفوظ محليًا بخوارزمية PBKDF2 + salt؛ اختر MENU أو الضغط المطوّل على بطاقة التطبيق لقفله أو إضافته للمفضلة. ليس قفلًا على مستوى النظام ويمكن تجاوز استخدام التطبيقات من واجهات أخرى.
- لوحة الأرقام مصممة للتحكم بالريموت بدون الاعتماد على لوحة مفاتيح افتراضية.
- تبقى إجراءات خيارات المطوّر عبر واجهة Android الرسمية فقط. لا روت ولا ADB تلقائي.
- تطبيق بدون صلاحية إنترنت؛ صلاحيات معلومات حالة الشبكة فقط لعرض الاتصال. لا يرسل بياناتك.
