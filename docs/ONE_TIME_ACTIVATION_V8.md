# العز TV v8 — تفعيل مرة واحدة

- يظهر PIN عند أول فتح للتطبيق فقط. وعند النجاح، تخزن حالة التفعيل في SharedPreferences الخاص بالتطبيق بشكل دائم.
- عند مغادرة التطبيق أو إغلاقه أو إعادة تشغيل الشاشة لن يطلب الرمز مرة أخرى.
- مسح بيانات التطبيق أو تغيّر معرف الحزمة يؤدي لفقدان التفعيل ويجب إدخاله مرة أخرى.
- معرف الحزمة الجديد sa.alezz.tv.unified لتجنّب تعارض تواقيع GitHub السابقة؛ لاحقًا يلزم استخدام توقيع Android نفسه للحفاظ على ترقية التطبيق وبياناته.
- التصميم: واجهة تلفزيونية RTL وقائمة جانبية وريموت، أقسام الأطفال والأفلام والقنوات ويوتيوب.
- رمز PIN محلي وليس مصادقة حساب Supabase؛ لا يحمي قاعدة البيانات العامة من الوصول بدون التطبيق.
- لوحة الإدارة تتطلب Supabase Auth وصلاحية مسؤول نشط، مستقلة عن الرمز العام.
