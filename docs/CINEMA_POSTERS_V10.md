# العز TV — إصدار 10.0.0 | Cinematic Posters

تحديث خاص بتطبيق Android TV بنظام Android 4.4.4 (API 19) والإصدارات الأحدث.

## ما الجديد
- بوسترات أفلام ومسلسلات طولية كاملة بتأثير **CenterCrop**، بدل الصور الأفقية المقتطعة.
- بطاقات قنوات ومقاطع أفقية لتناسب طبيعة المحتوى.
- شعار **العز TV** مدمج محليًا يظهر افتراضيًا عند غياب أو فشل صورة الفيلم (يعمل دون إنترنت).
- ثلاث محاولات آمنة للحصول على الصور: بوستر، خلفية، ثم الصورة المصغرة من YouTube الرسمي عند توفرها.
- صفحات الرئيسية والتفاصيل تعرض خلفية سينمائية تغطي كامل المساحة، مع طبقة تدرّج لتحسين وضوح العنوان.
- تركيز واضح بالريموت وزر تشغيل يظهر على الكرت عند تحديده؛ دعم أزرار الاتجاهات وOK.
- تحسين محمّل الصور في الخلفية، انتقال ظهور ناعم، ذاكرة محدودة لأجهزة التلفزيون القديمة ودعم TLS المستخدم سابقًا.
- تدرج جودة صور البوسترات حتى 1000×1200 بدل الحد الأفقي السابق؛ خفض المخاطر بحد تحميل 5 MiB لكل صورة.
- استمرار الربط بمكتبة Supabase المنشورة والمعتمدة دون تغيير صلاحياتها.

## التثبيت والتحديث
- الحزمة: `sa.alezz.tv.unified`
- `minSdkVersion=19`، `versionCode=16`، `versionName=10.0.0-cinema-posters`.
- يُنشر ملف APK كـ Release فقط عند وجود مفتاح توقيع دائم محفوظ في GitHub Secrets. وإلا فهو **APK تجريبي موقّع بتوقيع debug** ضمن GitHub Actions، وقد يتطلب إزالة النسخة الموقعة بمفتاح مختلف قبل التثبيت. احفظ بيانات التطبيق أولًا، لأن إزالة النسخة تحذفها.
- تحقق من التثبيت والتنقل والتشغيل على جهاز Android 4.4.4 حقيقي؛ نجاح البناء وحده لا يضمن توافق مصادر الفيديو أو TLS على كل جهاز.

## ملاحظات
لا يتجاوز التطبيق حقوق المحتوى أو DRM. ويستمر بعرض السجلات المعتمدة للنشر من Supabase فقط. لا تتغير سجلات الأفلام بسبب هذا التحديث.
