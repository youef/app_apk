# العز TV — الإصدار 5.0 للتحكم بالريموت (Android 4.4.4)

## شاشة الاختبار
صورة شاشة Huidi SMART (SMART_PC822) بنظام Android 4.4.4/API 19 ومعالج نحو 1.4GHz وذاكرة RAM محدودة؛ يفضل تخفيف تحميل البطاقات.

## الريموت
- الأسهم الأربعة: الانتقال بين صفوف ومربعات المحتوى والقائمة الرئيسية وفق موقع الأزرار الحقيقي على الشاشة.
- OK / Enter: فتح بطاقة العمل، أو تشغيل الزر الحالي.
- رجوع: من الحلقات إلى التفاصيل، ومن التفاصيل إلى القائمة السابقة، ومنها إلى الرئيسية.
- زر Menu: الانتقال إلى الإعدادات؛ داخل مشغل الفيديو يفتح خيارات الجودة.
- زر Search (إن وجد): الانتقال لقائمة البحث.
- مشغل الفيديو: زر Play/Pause، أزرار 10 ثوان للتقديم والإرجاع، إظهار شريط التحكم بالأعلى والأسفل وOK، مع نقل التركيز قبل إخفاء الشريط التلقائي.
- تركيز واضح عند اختيار بطاقة؛ والانتقال التلقائي بالشريط الأفقي والرأسي دون لمس.

## الأداء
- كل قائمة تعرض 20 بطاقة مع أزرار الصفحة التالية/السابقة بدل حشد 80 بطاقة في الشاشة.
- الوضع الخفيف للصور متاح من الإعدادات.
- تسري صلاحيات وترخيص المحتوى عبر Supabase كما في السابق، ولا تُحذف قاعدة البيانات.

## التحميل والتثبيت
هذا الإصدار بملف APK واحد وminSdk 19 وتوقيع V1 (KitKat) ومعرف حزمة **sa.alezz.tv.remote** منفصل عن v4، لتجنب رفض التثبيت فوق إصدار يحمل توقيعًا مختلفًا. يثبت بجوار v4، ولا يهاجر مفضلة v4 تلقائيًا؛ لا تحذف النسخة القديمة قبل التجربة.

يتحقق GitHub CI من Build، DEX 035، معمارية ARMv7، APK ZIP وManifest، وتوقيع V1. **لا يوجد اختبار ريموت فعلي أو تشغيل على شاشة المستخدم، لذا تحتاج تجربة ميدانية.**

توقيع debug الناتج مؤقت؛ لإجراء تحديث لاحق على هذا المعرّف يجب حفظ شهادة توقيع دائمة في GitHub Secrets قبل إصدار جديد. لن تستبدل GitHub Actions الملف المنشور أول مرة بمفتاح توقيع مختلف.
