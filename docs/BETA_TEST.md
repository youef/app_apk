# أسيل TV — نسخة متكاملة تجريبية لـ Android 4.4.4

## قبل التثبيت
- هذه نسخة Debug تجريبية، وليست إصدارًا إنتاجيًا موقّعًا بمفتاح دائم.
- يجب إزالة نسخة المرحلة الأولى `sa.aseel.tv` قبل تثبيت النسخة الجديدة **فقط بعد موافقة المستخدم** وحفظ بياناته إن وجدت، لأن مفاتيح Debug قد تختلف بين عمليات GitHub Actions.
- على الشاشة: الإعدادات > الأمان > السماح بتثبيت التطبيقات من مصادر غير معروفة، ثم افتح ملف APK.
- التطبيق يحتاج اتصال HTTPS للوصول إلى كتالوج Supabase.
- لا تنشر التطبيق على متجر التطبيقات قبل توفير مفتاح توقيع ثابت واستكمال اختبار الجهاز.

## اختبار التوافق الفعلي
1. تثبيت APK على Huidi Smart SMART_PC822 / Android 4.4.4.
2. تشغيل التطبيق واختبار أسهم الريموت وزر OK والرجوع.
3. تجربة «الرئيسية / الأفلام / المسلسلات / القنوات / المفضلة / البحث / الإعدادات».
4. تحقق من عدم انهيار الشاشة أثناء التحميل أو انقطاع الشبكة.
5. تجربة MP4 H.264/AAC قانوني منخفض الدقة عند توافره.
6. جرّب حفظ موضع المشاهدة واستعادته بعد إعادة التشغيل.
7. افتح الإعدادات وسجّل الطراز، RAM، دقة الشاشة، API وKernel.
8. عند خطأ شهادة TLS أو تشغيل HLS أرسل رسالة الخطأ/سجل Logcat بدل تجريب ملفات APK عشوائية.

## حدود النسخة التجريبية
- حساب المشاهد ليس مفعلًا: المفضلة وتقدم المشاهدة محفوظان محليًا فقط.
- لوحة الإدارة تتطلب حسابًا موجودًا في Supabase Auth مع `aseel_admins.active=true`.
- لا يعرض التطبيق إلا المحتوى الذي اجتاز قواعد نشر الحقوق في RLS.
- HTTPS موثوق فقط؛ لا توجد آلية تتجاوز صلاحية الشهادة.
- ملاءمة ترميزات HLS والتشغيل على اللوحة الفعلية غير مضمونة دون اختبار.
