# العز TV — v3.0 Android TV

- واجهة سينمائية ذات هوية داكنة وحمراء وشعار العز TV.
- عرض عمل مميز، صفوف محتوى أفقية كبيرة، قوائم للأطفال والمفضلة، بحث وتنقل بالريموت.
- Supabase API كما هو، وتجدد المحتوى دون إعادة تنزيل APK.
- تشغيل الفيديو داخل التطبيق فقط MP4/HLS المباشر، مع اختيار الجودة ومراقبة التقطيع.
- يدعم Android 4.4.4 (API 19) من ناحية الـManifest وDEX والشهادة V1؛ يلزم اختبار الجهاز الفعلي.
- يحتفظ بمعرّف الحزمة السابق sa.aseel.tv.cinema حتى لا يتحول إلى تطبيق منفصل.
- توقيع GitHub Debug قد يختلف، فلا تزل نسخة قديمة قبل نسخ البيانات وتجربة التثبيت.
- الإصدار تجريبي، وليس شهادة نجاح تشغيل على التلفزيون الحقيقي.
