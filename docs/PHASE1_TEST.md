# أسيل TV — تعليمات فحص المرحلة الأولى

**هذا الإصدار تجريبي لا يحتوي على أفلام أو مسلسلات أو إنترنت.**

1. نزّل `aseel-tv-api19-install-test.apk` من GitHub Releases على الجهاز أو انقله إليه.
2. من إعدادات Android TV اسمح بالتثبيت من مصادر غير معروفة للتطبيق الذي يفتح ملف APK عند الحاجة.
3. ثبّت التطبيق باسم «أسيل | أفلام ومسلسلات».
4. افتح التطبيق دون إنترنت. يجب أن تظهر عبارة «تم تشغيل أسيل بنجاح».
5. جرّب أسهم الريموت، زر OK، ثم «عرض مواصفات هذه الشاشة».
6. سجّل نتيجة التثبيت والتشغيل، وصوّر صفحة المعلومات في التطبيق.

## إذا رفض التثبيت
- صوّر رسالة الخطأ كاملة (مثل «حدثت مشكلة أثناء تحليل الحزمة» أو «التطبيق ليس مثبتًا»).
- لا تنشئ APK آخر قبل تحديد سبب الرفض.
- إذا أمكن استخدام ADB: `adb install -r aseel-tv-api19-install-test.apk` ثم انسخ رمز `INSTALL_FAILED_...`.
- إذا ظهرت `INSTALL_FAILED_UPDATE_INCOMPATIBLE` فافحص تعارض شهادة التوقيع؛ **لا تحذف بيانات تطبيق قائم دون موافقة المستخدم**.
- لا تفترض أن تغيير minSdk أو targetSdk يحل المشكلة من دون سجل.

## شروط نجاح المرحلة
- يثبت التطبيق على شاشة Huidi Smart SMART_PC822 الفعلية.
- تفتح الشاشة بنجاح وتظهر رسالة النجاح.
- تعمل أسهم الريموت وزر OK.
- تظهر معلومات اللوحة والنظام ودقة العرض والذاكرة من الجهاز.
- لا يحدث انهيار عند فتح الصفحة أو إغلاقها.

حالة الاختبار على الجهاز: **لم يتم اختباره على الشاشة الفعلية بعد**.
