# العز TV v7 — YouTube TV داخل التطبيق

### الجديد
- مشغّل رسمي باستخدام YouTube IFrame Player API في صفحة HTTPS مستضافة على GitHub Pages.
- روابط الفيديو المدعومة: youtube.com/watch?v=، youtu.be/، youtube.com/shorts/، youtube.com/live/، youtube.com/embed/.
- قسم يوتيوب في التطبيق مع إمكانية لصق الرابط عبر ريموت التلفزيون أو لوحة المفاتيح، وعرض فيديوهات المحتوى المنشور.
- لوحة الإدارة تتيح إدخال `youtube_url` منفصل في الأفلام والحلقات والقنوات؛ النشر يتطلب اعتماد الحقوق وفق ضوابط المشروع.
- تشغيل داخل العز TV دون فتح متصفح خارجي أو استخراج ملفات البث.
- تحكم بوساطة أسهم الريموت وأزرار تشغيل/إيقاف/تقديم وإرجاع، مع إظهار شعار يوتيوب وأدواته الأصلية.
- قفل PIN الإصدار السابق مستمر قبل الوصول إلى المكتبة أو المشغّل.
- دعم MP4/HLS المباشر مستمر من دون تغيير.
- توافق البناء Android 4.4.4، API19، Java7، ARMv7، DEX035، توقيع V1.

### قيود مؤكدة
**YouTube يعتمد على خدمات حديثة وبث HTML5.** شاشات Android 4.4.4 القديمة قد لا تستطيع تحميل أو تشغيل iframe، حتى لو كان ملف APK صالحًا. الدعم داخل APK تجريبي ولا يمكن اعتباره مثبتًا على شاشة Huidi SMART_PC822 إلا بفحص تشغيل حقيقي على الجهاز. قد يمنع ناشر الفيديو التضمين، أو تتطلب المنصة HTTP Referer، أو تفرض قيودًا جغرافية.

لا تنزيل ولا استخراج ولا إعادة بث لملفات يوتيوب. لا نستطيع تجاوز قرار يوتيوب بعدم السماح بالتضمين.

### التثبيت
هذا الإصدار يستخدم Package ID جديدًا **sa.alezz.tv.youtube** لتجنب تعارض توقيع النسخ السابقة. يثبت بجانب v6، ولا ينقل بيانات المفضلة المحلية تلقائيًا. احذف الإصدارات القديمة فقط بعد تجربة v7 وحفظ البيانات إذا أردت عدم الالتفاف على القفل المحلي للإصدارات السابقة. ملف APK منشور لا يُستبدل بتوقيع Debug جديد.
