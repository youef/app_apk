# تقرير دمج Free-TV/IPTV في أسيل — 29 أكتوبر 2026

## المصدر
- المستودع: https://github.com/Free-TV/IPTV
- ملف البث العام: https://raw.githubusercontent.com/Free-TV/IPTV/master/playlist.m3u8
- القائمة المستوردة للمراجعة: `scripts/free-tv-candidates.json` (71 مصدرًا HTTPS/HLS مختارًا من 2,053 إدخالًا في القائمة).
- الأدلة: `scripts/free-tv-passed.json` ونتائج GitHub Actions، وليست كل قائمة Free-TV.

## معايير الفحص الثلاثة
1. يستجيب رابط المصدر عبر HTTPS وتظهر قائمة HLS صحيحة، مع استبعاد HTTP 403/404 وSSL المنتهي وDRM.
2. ينجح تنزيل جزء فيديو حقيقي MPEG-TS أو fMP4، وليس مجرد ملف قائمة m3u8.
3. بعد 16 ثانية يتقدم رقم المقطع المباشر `#EXT-X-MEDIA-SEQUENCE` أو يتغير اسم آخر مقطع، لتجنب قوائم VOD القديمة.

## النتائج
- 71 مرشحًا من Free-TV خضع لفحص مقطع البث، نجح 31 وفشل 40 في بيئة GitHub Actions.
- جميع المرشحين الـ31 الذين نجحوا اجتازوا أيضًا فحص تقدم البث المباشر.
- من هؤلاء: 21 قناة جديدة نُشرت لأسيل، ورابط TRT World استُبدل بالرابط الرسمي الأحدث دون تكرار.
- 9 مصادر MBC اجتازت اختبار الاتصال ولكن **لم تُنشر**؛ هذا الفحص لا يثبت تصريح دمجها في تطبيق طرف ثالث. ولا تُعاد استضافة أي قناة.
- لا يضمن نجاح GitHub Actions وصول السعودية أو المناطق الأخرى إلى نفس CDN، ولا يثبت توافق مشغل Android 4.4.4 مع كل مشفرات HLS.

## أسباب الاستبعاد
- روابط Rotana أعادت 403 (قيود وصول)، وبعض قنوات دبي غير قابلة للوصول من بيئة الاختبار.
- عدة روابط أعادت 404، وأخرى شهادات TLS منتهية أو قوائم HLS غير صالحة أو بث مشفر.
- فشل مصدر من شبكة GitHub لا يعني بالضرورة تعطل الخدمة داخل السعودية؛ لا تُفترض إمكانية تشغيله هنا دون اختبار محلي.

## المتابعة
- `.github/workflows/hls-segment-audit.yml` يفحص المقاطع دوريًا.
- `.github/workflows/free-tv-live-progress.yml` يفحص تقدم البث دوريًا، ويشمل قنوات أسيل القديمة.
- **هذه عمليات فحص وتقارير، ولا تخفي القنوات تلقائيًا في Supabase.** أي تغيير دائم لحالة النشر يجب أن يراجع نتائجه، لأن شبكة CDN قد ترفض طلبات آلية مؤقتًا.

## الحقوق
Free-TV قائمة روابط إلى بث مفتوح ومعلن من الناشرين، وليست تصريحًا عامًا لإعادة البث التجاري أو نسخ الأفلام والمسلسلات. أسيل يستدعي روابط القنوات الأصلية دون خادم إعادة بث. قبل أي استخدام تجاري أو إعادة توزيع، يجب مراجعة شروط صاحب القناة والحصول على موافقته عند الحاجة.

## مشاهدة Android 4.4
- يستخدم التطبيق `VideoView` الأصلي؛ دعم HLS يعتمد على العتاد والتشفير والشهادة.
- إن تعذر فتح القناة، استخدم زر «مشغل خارجي» بالمشغل لتجربة تطبيق متوافق مع KitKat.
- تأكد من توقيع APK قبل الترقية. لا تحذف نسخة مثبتة وبياناتها دون نسخة احتياطية.
