# العز TV v6 — التلفزيون السينمائي المحمي

## تنفيذ الإصدار
- واجهة Android TV أفقية كاملة بتصميم داكن وقائمة جانبية عربية RTL، مع تحكم كامل بالأسهم وزر OK.
- شاشة إدخال رمز من ستة أرقام تظهر **قبل فتح التطبيق أو قراءة المكتبة**، مع لوحة ريموت وإخفاء الأرقام ومنع المحاولات المتكررة.
- جرى تخزين بصمة الرمز باستخدام PBKDF2-HMAC-SHA1 وسالت منفصل بدل وضعه نصًا صريحًا في المصدر.
- يتم قفل واجهة التطبيق عند خروجها من الواجهة الأمامية، وإغلاق المشغل عند نقله للخلفية، فيلزم إدخال الرمز عند العودة.
- كل أقسام المحتوى والبحث والمفضلة والقنوات لا تظهر إلا بعد فتح الواجهة، والمشغل المباشر يعرض المحتوى بملء الشاشة.
- حد 20 بطاقة لكل صفحة لتقليل استهلاك RAM في شاشات Huidi القديمة.
- توافق Java 7 وAndroid 4.4.4 API19 وARMv7 مع TLS 1.2 حسب مزود التشفير؛ تصدير APK واحد وV1-signing.

## احتياطات وقيود مهمة
- هذه **حماية محلية داخل التطبيق فقط**؛ ليست نظام هوية خادميًا، ولا تمنع هندسة APK العكسية أو الوصول المباشر إلى البيانات العامة في Supabase، أو استخدام الموقع العام.
- الرمز من 6 أرقام قابل للتخمين أو الاستخراج بهجوم متقدم؛ لحماية حقيقية للمحتوى أو الدفع يلزم تسجيل دخول مع تحقق من الخادم وRLS وسياسات جلسات.
- إصدارات العز TV السابقة (v4 وv5.1) المثبتة لا تطلب الرمز، وتبقى منفصلة. بعد التأكد من نجاح هذا الإصدار ونقل ما تحتاجه، أزل القديمة إن أردت منع الوصول من خلالها.
- النسخة الجديدة تستخدم معرف الحزمة **sa.alezz.tv.locked** لمنع رفض تثبيتها بسبب اختلاف شهادات Debug القديمة. المفضلة في إصدارات أخرى لا تنتقل تلقائيًا.
- مفتاح التوقيع الدائم لم يُضبط بعد؛ التحديث المباشر فوق هذه النسخة يتطلب التوقيع **بنفس الشهادة**. يجمّد مسار CI أول ملف APK منشور بدل استبداله تلقائيًا.
- لا يمكن إثبات عمل كل أزرار الريموت أو التشغيل على جهاز Huidi الحقيقي قبل تجربته عليه. فحوص GitHub ثابتة فقط.
