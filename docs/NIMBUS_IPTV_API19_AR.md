# العز TV — IPTV والتوافق مع Android 4.4.4

## ملخص التحديث

هذه الإضافة مستوحاة من أفكار الاستقرار ودليل البرامج في مشروع Nimbus، لكنها تنفيذ Java مستقل لتوافق Android API 19. لم تُنسخ ملفات أو أصناف Nimbus؛ ولا تغير هذه الإضافة ترخيص مشروع العز TV.

- استيراد M3U من إعدادات التطبيق باستخدام HTTPS فقط.
- حفظ رابط القائمة محليًا على الجهاز؛ لا تُنسخ القنوات إلى Supabase.
- دعم group-title واسم القناة والشعار وtvg-id.
- دعم دليل XMLTV اختياريًا وعرض الآن / التالي عند تطابق معرف القناة.
- المصادر يتم فحصها عند التشغيل ولا تُعد موثقة لمجرد الاستيراد.
- حدود تنزيل M3U حتى 12 ميجابايت وXMLTV حتى 24 ميجابايت، عدد القنوات 2500، ومهلات مع إعادة توجيه HTTPS فقط.
- عرض أول 350 قناة في واجهة القائمة لتخفيف الضغط على الشاشة القديمة؛ البحث يتعامل مع جميع القنوات.
- نقل قائمة مجاورة محدودة إلى المشغل لتجنب تجاوز حجم Android Binder.
- استيراد المصادر المحفوظة عند بدء التطبيق، وتحديثها بعد 45 دقيقة من العودة إليه.
- مراقبة تجمد بث القناة ومحاولتا استعادة قبل اختبار رابط بديل.
- ضبط حجم التخزين المؤقت في ExoPlayer بحسب عمر الجهاز.

## الاستخدام

1. افتح الإعدادات ثم قنوات IPTV من جهازك.
2. أدخل رابط M3U صالحًا بصيغة HTTPS.
3. اختياريًا أدخل رابط XMLTV بصيغة HTTPS.
4. اضغط استيراد القنوات وتحديث دليل البرامج.
5. ادخل البث المباشر أو البحث واختر القناة.
6. لإزالة المصادر المحلية فقط اضغط حذف قائمة IPTV المحلية.

## حدود العمل

- لا يوفر التطبيق قنوات أو يتجاوز DRM أو 403 أو قيود الترخيص والجغرافيا.
- يظل توافق ترميز الصوت والفيديو مع Android 4.4.4 مرتبطًا بقدرات الجهاز.
- التخزين المؤقت المحسن ليس DVR ولا يوفر تسجيل/إرجاع البث بمفرده.
- يحتاج التحديث والتثبيت اختبارًا على شاشة فعلية. نجاح بناء GitHub Actions ليس اختبار تشغيل.
- يحتاج تحديث التطبيق بنفس المعرف إلى مفتاح توقيع ثابت.
