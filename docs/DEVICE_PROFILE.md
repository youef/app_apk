# ملف الجهاز المستهدف — Huidi Smart SMART_PC822

**بيانات سابقة من المستخدم (غير مؤكدة آليًا من الجهاز):**
- Vendor/اسم الشاشة: Huidi Smart SMART_PC822
- Board: CVTE
- Android: 4.4.4 KitKat / API 19
- CPU: ARM Cortex-A7 dual core
- ABI: ARM 32-bit
- Kernel: Linux 3.10.40

**قيمة غير معروفة حتى تُقرأ من الشاشة الفعلية:**
- إجمالي RAM
- الدقة الفعلية المتاحة للتطبيق وDPI
- قيم Build.MANUFACTURER / Build.MODEL / Build.HARDWARE
- Android build fingerprint
- قيود Package Manager وسبب الرفض السابق

**طريقة الجمع:** زر «عرض مواصفات هذه الشاشة» في نسخة الاختبار. لا تنسخ بيانات نظام التشغيل من الاسم التجاري وحده.

**سبب اختيار APK بلا native libraries:** عدم حاجة التطبيق إلى ABI خاص، وتقليل احتمال رفض الجهاز بسبب معمارية غير مدعومة.

**تعارض النسخ القديمة:** أشار المستخدم إلى أن أول APK ثُبّت وآخر APK رُفض. قد يكون اختلاف شهادة التوقيع. لهذه البداية معرّف حزمة جديد ثابت هو `sa.aseel.tv`، دون الكتابة فوق التطبيق السابق.
