# العز TV – إضافة فحص Chrome المحلية

هذه إضافة **Manifest V3** تعمل على Chrome للكمبيوتر بعد أن يفتح المستخدم التبويب ويضغط زر الفحص بنفسه.

## التثبيت
1. نزّل مجلد `chrome-extension/alezz-media-inspector` إلى جهاز الكمبيوتر.
2. افتح `chrome://extensions` وفعّل **Developer mode**.
3. اختر **Load unpacked** وحدد المجلد.
4. افتح صفحة HTTPS تريد تشخيصها، ثم اضغط أيقونة الإضافة > **فحص التبويب الحالي**.
5. اضغط **نسخ التقرير JSON** والصقه في قسم الإضافة بصفحة استوديو العز TV.

## الصلاحيات
- `activeTab`: الوصول المؤقت للتبويب الحالي فقط عند تفاعل المستخدم.
- `scripting`: تنفيذ فحص في صفحة التبويب الحالي.
- لا توجد `host_permissions` عامة، ولا `cookies` أو `webRequest` أو `downloads`.
- لا إرسال تلقائي إلى أي API؛ لا تجمع كلمات مرور أو رموز جلسات أو قيم Cookies.
- روابط المصدر لا تُدرج في التقرير؛ فقط إحصاءات الوسائط وأنواع الموارد.
- مؤشرات Performance ليست بديلًا عن عرض Network الكامل في DevTools.

هذا المشروع للتشخيص والمراجعة على الصفحات المصرح بها فقط؛ لا يوفر تجاوز DRM أو حظر 403 أو تنزيل محتوى محمي.

## ملاحظة
إضافات Chrome المكتبية لا تعمل داخل Safari على iPhone. استخدم إصدار الكمبيوتر للفحص المحلي.
